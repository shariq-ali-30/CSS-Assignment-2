# Amazon Clone

## About The Project

This project is an Amazon homepage clone created using HTML and CSS.

The purpose of this assignment was to practice CSS styling, layouts, flexbox, positioning, colors, hover effects, and creating a real-world website interface by recreating the design and structure of an e-commerce website.

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

## Features

- Amazon-style navigation bar
- Logo, search bar, and account sections
- Location and cart section design
- Hero banner section
- Product category cards layout
- Multiple product sections with images
- Footer with multiple information sections
- Hover effects on navigation elements
- Responsive structured layout using CSS Flexbox
- Custom styling with CSS classes

## What I Learned

Through this assignment, I learned:

- How to create a website layout using HTML and CSS
- How to use CSS Flexbox for arranging elements
- How to design navigation bars and sections
- How to create reusable CSS classes
- How to add icons using Font Awesome
- How to style cards and image backgrounds
- How to apply hover effects and transitions
- How real-world websites organize their structure
